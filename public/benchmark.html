Experimental. Not production. Nothing here is wired into the AI engine.
Observation only. All candidates run with the same diagnostic score floor (0.05) and no category allowlist, so every class is visible and the comparison measures the models rather than our thresholds. Class identity uses each model's own index map — SSD MobileNetV2 has a background class at index 0, so its person/phone indices are 1 / 77 while EfficientDet uses 0 / 76. No imagery is stored.
